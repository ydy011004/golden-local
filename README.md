# 黄金价格实时看板

一个仅用 Python 标准库实现的本地 HTTP 小服务：启动后浏览器实时展示国际金价、人民币汇率、换算后的人民币/克金价、上海黄金交易所 Au99.99 延时价格，以及内外价差与刷新走势图。

## 功能特性

- **国际金价换算**：XAU/USD（美元/盎司）与 USD/CNY 换算为人民币/克 = XAU/USD × USD/CNY ÷ 31.1034768
- **中国金价**：上海黄金交易所 Au99.99 延时报价（元/克）
- **内外价差**：中国报价 − 换算后国际报价，正值表示国内报价高于国际
- **刷新走势图**：canvas 折线图，支持坐标轴刻度、网格线、图例和鼠标悬浮提示
- **自动刷新**：默认 10 秒，可在 10 / 30 / 60 秒间切换，也可手动刷新
- **多数据源降级**：XAU/USD、USD/CNY、Au99.99 各有多个备用源，按优先级自动切换
- **缓存容灾**：所有实时源失败时自动读取上次成功保存的 `gold_cache.json`，页面标注“缓存数据”及失败原因；无缓存才返回 500
- **多线程服务**：`ThreadingHTTPServer` 可同时处理多个浏览器请求；浏览器在独立线程中打开，不阻塞服务

## 环境要求

- Python 3.8+（仅标准库，无需安装第三方依赖）

## 快速开始

```powershell
py gold_local_server_v5_1_fixed_cache.py
```

启动后自动打开浏览器访问 http://127.0.0.1:8000（只监听本机，不暴露给局域网）。也可手动访问该地址。

## 数据来源与优先级

| 数据 | 数据源（按优先级） |
| --- | --- |
| XAU/USD | Stooq 当前 CSV → Stooq HTML → GoldPrice.org → Metals.live → Yahoo Finance → Stooq 日线 → FreeGoldAPI 日更 CSV |
| USD/CNY | ExchangeRate-API → ExchangeRate.host → Stooq 当前 CSV |
| Au99.99 | SGE 中文延时行情 → SGE 英文延时行情 → SGE 日报（最近 10 天） |

## 缓存与日志

- `gold_cache.json`：最近一次成功获取的行情缓存
- `gold_debug.log`：各接口的失败原因（调试用）
- V5.1 起缓存与日志固定存放在 `D:\桌面\golden-local`，不再随运行目录变化；两者均已加入 `.gitignore`

## 常见问题

- **服务启动后页面打不开**：确认 8000 端口未被占用（`netstat -ano | findstr 8000`）。已修复浏览器自动打开阻塞服务的问题（浏览器改为在线程中打开）。
- **页面显示“缓存数据”**：当前所有实时数据源都不可用，展示的是最近一次成功获取的缓存行情。
